# Retail Sales Analysis Using SQL & Power BI

## Project Overview
This project analyzes retail sales data using MySQL and Microsoft Power BI to identify sales trends, profit patterns, product performance, and customer behavior.

## Project Objectives
- Analyze total sales and profit.
- Identify top-performing products and categories.
- Compare sales across states and cities.
- Analyze customer segments.
- Understand discount patterns.
- Generate useful business insights.

## Tools Used
- MySQL
- Microsoft Power BI

## Project Files
- SQL File – Contains SQL queries for data analysis.
- Power BI File (.pbix) – Contains interactive dashboards.

## Dashboard Pages
1. Retail Sales Performance Dashboard
2. Detailed Analysis
3. Sales Insights
4. Customer & Discount Analysis

## Key Metrics
- Total Sales
- Total Profit
- Total Orders
- Total Quantity Sold
